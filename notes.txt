Chốt lại lệnh Build cho Vercel
Khi bạn lên trang web của Vercel để Import repo GitHub vào, ở phần Build & Development Settings, bạn hãy kiểm tra kỹ các thông số này để nó khớp với kiến trúc của bạn:

Framework Preset: Angular

Build Command: npm run build

Output Directory: dist/elearning-frontend/browser (Nhớ có chữ /browser ở đuôi, đây là nơi chứa bản build tĩnh của Angular).

Install Command: npm install --legacy-peer-deps (Ghi đè lệnh cài đặt mặc định của Vercel để nó không bị lỗi xung đột Firebase).
